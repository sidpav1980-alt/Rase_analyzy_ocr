# Trail Race Analyzer v0.33 — ONLINE FULL

## VO₂max как резервный скоростной якорь
Если загруженная **Скоростная плоская GPX** заметно медленнее, чем позволяет введённый VO₂max, модель больше не обязана считать этот медленный тренировочный темп максимальной скоростью спортсмена.

Логика:
- сначала берётся фактическая скорость из скоростной плоской GPX;
- по VO₂max рассчитывается консервативная скоростная оценка для 5–15 км;
- если файл не медленный относительно VO₂max — используется файл;
- если файл медленнее оценки более чем примерно на 8% — применяется смесь файла и VO₂max;
- доля VO₂max растёт при более сильном расхождении, но ограничена 70%;
- VO₂max не заменяет GPX полностью и не используется как показатель выносливости.

В карточке «Калибровка» показывается, когда VO₂max вошёл в скоростной якорь и с каким весом.

Остальная модель сохранена:
скоростной якорь → Riegel → рельеф → запас выносливости → длительность → анализ покрытия/броды.
