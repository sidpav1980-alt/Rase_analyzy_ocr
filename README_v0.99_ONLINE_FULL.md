# Trail Race Analyzer v0.99 ONLINE FULL

Исправлена группировка бродов.

Правило:
- водоток с известной шириной < 1 м не считается бродом;
- несколько пересечений в пределах 0.5 км от ПЕРВОЙ точки группы считаются одним бродом;
- используется не цепочная дедупликация, поэтому соседние группы не сливаются бесконечно.

Пример:
- 6.3, 6.5, 6.7 км → 1 брод: 6.3–6.7;
- 7.1, 7.2 км → следующий брод: 7.1–7.2;
- 16.0, 16.1 км → 1 брод: 16.0–16.1.
