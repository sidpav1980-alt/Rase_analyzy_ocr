# Trail Race Analyzer v0.86 ONLINE FULL

## v0.86
- В раздел «Итог» добавлена **Пульсовая стратегия**.
- Стратегия строится автоматически из:
  - длины GPX трассы;
  - среднего пульса «Лучшей тренировки».
- Гонка делится на 4 участка:
  - начало — контролируемый пульс;
  - середина — рабочий горный диапазон;
  - поздняя часть — постепенное повышение;
  - последние ~5% — финиш без экономии при хорошем состоянии.
- На спусках приложение отдельно напоминает не удерживать высокий пульс искусственно.
- При смене фото/очистке тренировки старая пульсовая стратегия очищается.
- Все изменения v0.85 сохранены.

# Trail Race Analyzer v0.84 ONLINE FULL

## v0.84
Исправления раздела «Лучшая тренировка»:

- После выбора файла и нажатия «Загрузить и распознать» выбранный скриншот больше не сбрасывается.
- Имя выбранного файла дополнительно показывается отдельной строкой и остаётся видно после OCR.
- При выборе новой фотографии очищаются только старые результаты и поля тренировки, но новый выбранный файл сохраняется.
- При обновлении страницы поля принудительно очищаются несколько раз:
  - сразу после загрузки DOM;
  - после первого кадра;
  - через 120 мс;
  - через 500 мс;
  - при Safari `pageshow`.
  Это сделано потому, что Safari может восстанавливать значения формы уже после `DOMContentLoaded`.
- На настоящем обновлении страницы также очищается выбор файла.
- OCR timeout 60 секунд сохранён.
