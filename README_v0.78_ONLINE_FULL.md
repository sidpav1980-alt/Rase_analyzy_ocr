## v0.78
- Нижний блок ручного редактирования данных тренировки сохранён.
- Его поля переименованы как верхние результаты OCR: «Расстояние», «Время в движении», «Средний темп», «Средний пульс».
- После OCR эти четыре поля заполняются автоматически и остаются доступными для ручной корректировки.
- Исправлено распознавание Garmin/Strava: расстояние не должно путаться с темпом; отдельно извлекаются время в движении и средний пульс.
- OCR не имеет искусственного таймаута.
