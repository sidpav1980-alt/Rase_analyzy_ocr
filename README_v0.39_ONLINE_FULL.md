## Текущая логика прогноза

Используются три эталона:
1. **Силовая трейловая GPX** — уклон, набор и запас выносливости.
2. **Быстрая трейловая GPX** — рабочая скорость на трейле и реакция на умеренный рельеф.
3. **Скоростная плоская GPX от 5 км** — основной скоростной якорь; при слишком медленном файле может частично корректироваться по VO₂max.

Базовая последовательность расчёта:
**скоростной якорь → Riegel → рельеф → запас выносливости/усталость → VO₂max → анализ покрытия.**

При прогнозе с анализом GPX:
- тропа: +1:00 мин/км;
- грунт: +0:30 мин/км;
- неизвестно: +1:00 мин/км;
- брод: +40 сек;
- мост: без отдельного штрафа.

В AUTO-разбиении таблицы соседние одинаковые покрытия объединяются. Если анализ трассы отсутствует, используется разбиение по 5 км.

### v0.37
Для участков покрытия **«неизвестно»** введён минимальный расчётный темп **6:30/км**. Если базовая модель даёт быстрее, неизвестная доля участка считается по 6:30/км; если модель уже даёт медленнее 6:30/км, темп дополнительно не ускоряется.


### v0.38
В таблицу прогноза добавлен **целевой пульс по каждому участку**. Он рассчитывается из среднего пульса загруженных тренировок (или LTHR, если он задан), предполагаемого темпа конкретного участка и накопления усилия по ходу гонки. Быстрые участки получают более высокий целевой пульс, медленные/технические — более низкий; старт ограничивается консервативнее, к финишу допускается рост.


### v0.39
Целевой пульс теперь читается непосредственно из HR-данных загруженных тренировочных GPX (`gpxtpx:hr` и другие namespaced `<hr>`). Для каждого эталона рассчитываются средний HR и зависимость HR от скорости. Пульс по участку корректируется по прогнозному темпу, уклону и стадии гонки. Более длительные тренировочные GPX получают немного больший вес для устойчивого HR-якоря. Если в GPX нет HR, используется ручной средний пульс или LTHR; если HR-данных нет вообще, выводится «—».
