# Trail Race Analyzer v0.32 — ONLINE FULL

Изменено требование к третьему эталону **«Скоростная плоская GPX»**.

- Минимальная длина: **5 км** вместо 10 км.
- Файл 5 км и длиннее принимается как скоростной плоский эталон.
- Если GPX короче 5 км, выводится ошибка: «Скоростная плоская GPX должна быть не менее 5 км».
- Формула Riegel теперь может масштабировать скоростной якорь начиная с 5 км.
- Остальная логика прогноза v0.31 сохранена.
