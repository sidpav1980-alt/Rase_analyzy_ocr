# Trail Race Analyzer v0.31 — ONLINE FULL

Исправлено поведение при замене любого из 3 эталонных GPX.

## Теперь при выборе нового файла
Сразу очищаются:
- прогноз движения;
- средний темп;
- диапазон;
- калибровка;
- коэффициент длительности;
- ограничение по пульсу;
- расчётное время до закисления;
- влияние VO₂max и подпись VO₂max;
- таблица участков;
- итоговый расчёт.

## После нажатия «Загрузить ... GPX»
Если трасса, все 3 эталона и VO₂max готовы, прогноз автоматически считается заново.

Если раньше был выбран режим «с анализом GPX» и анализ текущей трассы всё ещё действителен, пересчёт остаётся в этом режиме. В остальных случаях выполняется обычный прогноз по трассе.

Исправлены неправильные ID полей очистки (`raceModelSource`, `raceAcidTime`, `raceVo2Value`), из-за которых часть старых цифр в v0.30 оставалась на экране.
