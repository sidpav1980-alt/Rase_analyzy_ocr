# Trail Race Analyzer v0.94 ONLINE FULL

## v0.94
- VO₂max в разделе «Прогноз» теперь **обязателен**.
- Допустимый диапазон: **20–90 мл/кг/мин**.
- Без VO₂max кнопка расчёта прогноза не активируется.
- Для расчёта одновременно требуются:
  1. GPX трассы гонки;
  2. Силовая трейловая GPX;
  3. Быстрая трейловая GPX;
  4. Гоночная (плоская) GPX;
  5. VO₂max.
- Убрана старая подпись `activity preset`: до готовности модели показывается `нужно 3 GPX + VO₂max`.
- VO₂max остаётся умеренной поправкой к скорости; главные ограничения длинной гонки — пульс и длительность.
