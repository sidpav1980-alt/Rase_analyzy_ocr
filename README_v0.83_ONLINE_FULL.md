## v0.83
- Удалён второй дублирующий блок «Скриншот тренировки» с кнопкой «Загрузить и обработать скриншот».
- Оставлен только верхний основной OCR-блок.
- Удалена старая кнопка «Заполнить из текста», относившаяся к дублирующему блоку.
- Поля «Лучшая тренировка» теперь принудительно очищаются:
  - при обычном обновлении страницы;
  - при повторном открытии страницы из Safari back/forward cache;
  - при выборе новой фотографии.
- Очищаются: Расстояние, Время в движении, Средний темп, Средний пульс, OCR-процент и время обработки.
- У полей отключено браузерное автозаполнение.
- Лимит OCR 60 секунд сохранён.
