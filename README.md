# v1.07 — группировка бродов по водному объекту

- Пересечения сначала связываются с конкретным OSM waterway/water object.
- Несколько рукавов одной и той же реки/ручья объединяются в один физический брод.
- Для одного OSM-объекта рукава до 400 м по ходу трека могут быть объединены.
- Разные OSM-объекты объединяются только если практически совпадают (до 180 м).
- Подтверждённый ford=yes имеет приоритет над вероятным пересечением.
- Пересечения рядом с мостом (80 м) исключаются из бродов.
- Мостовые пересечения показываются отдельно.
- Остальные изменения v1.06 сохранены.
