# v0.84

- На старте симуляции с общей вероятностью 30% выпадает ровно одно состояние:
  Усталость, Удача или Демотивация.
- Усталость: +30 минут до ближайшего ПП.
- Удача: +20% к вероятности положительных событий.
- Демотивация: три отрицательных события подряд = DNF.
- Одновременно несколько стартовых состояний теперь невозможны.
- Карта/схема GPX возвращена в «Трек гонки → Анализ карты».
- При завершении анализа и при смене GPX карта принудительно перерисовывается.
- В «Симуляции гонки» карта по-прежнему скрыта.
