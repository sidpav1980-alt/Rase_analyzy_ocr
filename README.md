# Trail Race Analyzer v0.0231

- В симуляции добавлена кнопка «Симуляция трека 20 км».
- Виртуальный трек работает без GPX и без расчёта реального прогноза.
- Виртуальная трасса: 20 км, суммарный набор +500 м.
- Два виртуальных брода: 6.0 и 14.0 км.
- Базовое виртуальное время: 2:00:00; случайные события и экипировка работают как в обычной симуляции.
- При выборе/загрузке реального GPX виртуальный трек отключается, а текущая симуляция сбрасывается.
- Сохранены изменения v0.0230 и фильтрация ложных городских бродов.
