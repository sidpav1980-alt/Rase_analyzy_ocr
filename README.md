# Прогноз и анализ трейловых гонок — v0.61

Изменения:
- жёсткий таймаут анализа карты: 20 секунд;
- на 20-й секунде запрос прерывается, прогресс скрывается, кнопка снова становится доступна;
- выводится сообщение, что можно повторить анализ или считать прогноз без анализа карты;
- пояснение «Зачем нужен анализ карты?» теперь постоянно видно и не исчезает после загрузки GPX;
- пояснение перечисляет тропы, грунт, асфальт, воду и броды;
- обновлён cache/version до v0.61.
