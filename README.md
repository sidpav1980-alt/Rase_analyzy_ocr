# Trail Race Analyzer v0.0241

Исправления перехода между виртуальными уровнями:
- После победы на уровне жизни явно восстанавливаются до 3/3.
- После прохождения уровня следующий виртуальный трек сразу перестраивается.
- Профиль, дистанция, набор высоты, броды и ПП обновляются на данные нового уровня.
- На втором уровне больше не остаётся карта/профиль первого уровня.
- Реальный трек и его симуляция не затронуты.

- «Остановились пофоткать»: штраф изменён на +3:00 к времени гонки.

- В виртуальном чемпионате 1 место: финишное время должно быть строго быстрее времени прогноза.

- В панели виртуального чемпионата добавлен явный текст: чтобы занять 1 место, нужно финишировать быстрее времени прогноза.
- Логика v0.0243 сохранена.

- В виртуальном чемпионате добавлена подсказка: для старта нужно пройти проверку обязательной экипировки.

- Исправлен диапазон ±10% в прогнозе с анализом GPX: нижняя граница 90%, верхняя 110% от прогноза.

- Для гонок до 15 км диапазон прогноза сужен до реалистичного: примерно 97%–104.5% от центрального прогноза.
- Подпись «Диапазон ±10%» заменена на «Реалистичный диапазон».
- На преимущественно асфальтовых городских маршрутах вероятные броды в первом километре не учитываются; подтверждённые OSM-броды остаются.

- Для коротких гонок быстрая граница реалистичного диапазона изменена с 97% на 93.8% от центрального прогноза; при 42:07 это около 39:30.

- Исправлен анализ преимущественно асфальтовых трасс: при >=80% paved OSM-разрывы, water/unknown и короткие ошибочно классифицированные trail/dirt участки не получают трейловые штрафы.
- Подтверждённые броды по-прежнему учитываются отдельно.

- Во вкладке «Трек гонки» добавлен ручной режим «Асфальтовый трек».
- Можно ввести дистанцию от 0.1 до 600 км и создать ровную трассу без GPX.
- Для такого трека набор/сброс = 0 м, покрытие = 100% асфальт, броды/вода/тропа/грунт = 0.
- Ручной асфальтовый трек доступен обычному прогнозу, прогнозу с анализом и симуляции реального трека.

- v0.0254: исправлена критическая ошибка прогноза на 61–100 км: показатель Riegel был 0.0200 вместо 1.105, из-за чего 100 км считались примерно как 10 км.

- v0.0255: кнопка «Асфальтовый трек» после выбора становится зелёной и показывает «✓ Асфальтовый трек активен». При выборе GPX возвращается в обычное состояние.

- v0.0257: в ручной асфальтовый трек добавлен ввод набора высоты 0–50000 м, по умолчанию 0 м. Набор участвует в профиле и прогнозе.

- v0.0258: поле ChatGPT/OpenAI API key удалено из стартового списка.
- Стартовый список может сразу содержать ITRA PI; приложение распознаёт колонку PI.
- Поиск ITRA выполняется автоматически пакетами максимум по 50 участников через серверный /api/itra-batch.
- После заполнения PI можно сохранить обогащённый стартовый список CSV на iPhone; исходные колонки сохраняются и добавляется/обновляется ITRA PI.

- v0.0260: сообщение «1 МЕСТО» показывается 5 секунд; переход к следующему уровню виртуального чемпионата задерживается до окончания этого показа.

- v0.0261: «Загрузить список с баллами ITRA» теперь реально открывает отдельный XLSX/CSV, а не запускает AI/API-поиск.
- После успешной загрузки список ITRA заменяет обычный стартовый список; обычный список визуально отключается и выводится явное уведомление.
- Добавлена кнопка возврата к обычному списку.
- «Рассчитать прогноз гонки по баллам ITRA» теперь действительно считает вероятности и медианное место по введённому своему PI.
- Устаревший текст про автоматический поиск пакетами по 50 удалён.
