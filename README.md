# Trail Race Analyzer v0.0234

- Над правой колонкой случайных событий добавлена общая подпись «Ко времени гонки».

  - 7–20 км — ровно до финиша.
- На виртуальном треке один брод — 6.0 км.
- Вернул свободное переключение между «Симуляция трека 20 км» и «Симуляция реального трека».
- Выбранный режим подсвечивается зелёным, но вторая кнопка остаётся активной.
