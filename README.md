# Trail Race Analyzer v0.52 ONLINE FULL

## Более консервативный прогноз на экстремально вертикальных трассах

Исправлена ситуация, когда быстрый плоский эталон и VO₂max слишком сильно ускоряли прогноз на трассе с огромным набором.

### Новая логика
- После ~80 м+/км штраф за вертикальность становится **нелинейным**.
- Сравнивается вертикальная плотность трассы и силового GPX.
- Если трасса в 2–3 раза вертикальнее силовой тренировки, km-effort больше не считается достаточной поправкой.
- Чем выше м+/км, тем меньше допустимое улучшение относительно силового эталона.
- Если GPX самой трассы содержит временные метки предыдущего прохождения, его **moving time** используется как дополнительный same-course anchor.
- Для ≥140 м+/км модель не предполагает улучшение более чем примерно на 12% относительно реального moving time того же GPX без дополнительных оснований.

Пример: трасса 17.1 км / +2727 м (~159 м+/км), имеющая реальное moving time около 4:43, больше не должна прогнозироваться около 3:20. Reality-check даёт нижнюю границу примерно около 4:09, после чего могут добавляться остальные штрафы модели.

Остальная логика v0.51 сохранена.
