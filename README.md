# v1.06 — подсчёт бродов

- Близкие точки/рукава одного водного пересечения объединяются, если расстояние между ними до 150 м.
- Разные пересечения с разрывом 200 м и более больше не склеиваются в один брод.
- Пересечение воды рядом с отмеченным мостом (радиус 80 м) исключается из бродов.
- Подтверждённые и вероятные броды дедуплицируются между собой.
- Списки километров и общее количество теперь используют ту же логику группировки.
- Все изменения v1.05 сохранены.
