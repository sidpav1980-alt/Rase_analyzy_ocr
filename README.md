# v0.0203 — количество событий по длительности

- Около 1 часа: ровно 3 события.
- Около 2 часов: 4–6 событий.
- Около 3 часов: 5–7 событий.
- Около 4 часов: 6–8 событий.
- Около 5 часов: 7–9 событий.
- Около 6 часов: 8–10 событий.
- На более длинных гонках количество продолжает постепенно расти.
- Баланс положительных/отрицательных событий 50/50 сохранён.
