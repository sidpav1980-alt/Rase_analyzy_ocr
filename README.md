# Trail Race Analyzer v0.50 — ONLINE FULL

## v0.50 — HR-модель по распределению тренировок

Пульсовый прогноз переработан.

Теперь из каждого тренировочного GPX считываются:
- средний HR;
- медиана HR;
- 75-й, 90-й и 95-й процентили;
- максимальный HR;
- зависимость HR от скорости.

Логика:
- **Скоростная плоская GPX** задаёт верхний рабочий и пороговый пульсовый ориентир.
- Более длительные GPX задают устойчивый пульс для длинной гонки.
- Длительность предстоящей гонки определяет, насколько целевой HR смещается от скоростного ориентира к устойчивому.
- Темп участка влияет умеренно; медленный горный темп больше не должен искусственно снижать HR на 10–15 уд/мин.
- Подъём допускает более высокий HR, спуск не требует удерживать высокий пульс.
- На финише верхняя граница ограничивается реально наблюдавшимся HR в скоростной тренировке.

Если скоростная десятка имеет, например, средний HR около 175, приложение больше не должно строить рабочую модель так, будто верхний ориентир спортсмена находится около 160.

Остальные функции v0.49 сохранены.
