# Прогноз и анализ трейловых гонок — v0.60

## Изменения
- Анализ карты автоматически прерывается через **20 секунд**.
- Добавлено пояснение: анализ карты нужен для улучшенного прогноза, потому что определяет тропы, грунт, асфальт, воду и броды и использует эти данные для корректировки темпа и времени.
- Обычный прогноз по GPX остаётся доступен, если анализ карты не завершился.
- Исправлено обновление версии после деплоя:
  - Service Worker переведён на network-first для страницы;
  - cache version → `trail-analyzer-web-v060`;
  - JS/CSS получили `?v=060`;
  - браузер принудительно проверяет обновление Service Worker после загрузки.

### Почему раньше оставалась старая версия
В предыдущей сборке интерфейс показывал v0.59, но `sw.js` всё ещё использовал cache `trail-analyzer-web-v057` и отдавал `index.html` сначала из старого кэша. Поэтому Render мог успешно задеплоить новые файлы, а Safari/Chrome продолжали показывать старую страницу.
