# v1.04

- При выборе другого GPX текущий анализ карты останавливается сразу.
- Активный fetch к /api/osm или Overpass прерывается через AbortController.
- Старый анализ больше не переключается на резервные OSM-серверы после смены GPX.
- Блок «Анализ карты запущен…» сразу скрывается.
- Статус меняется на «Анализ карты остановлен: выбран новый GPX».
- Из v1.03 сохранено: Бобр +5:00, на 5-часовой гонке 6–10 событий, максимум 2 события/час.
