# Trail Race Analyzer v0.0237

Изменения:
- На виртуальном треке первый ПП всегда расположен на 7.0 км.
- При прохождении ПП:
  - запускается короткий музыкальный сигнал;
  - вокруг бегуна летят музыкальные ноты, смайлики и фрукты;
  - показывается уведомление о прохождении ПП.
- Остальная логика v0.0236 сохранена.

- При каждом новом запуске прохождения поправка к финишному времени обнуляется. Штрафы и бонусы предыдущей гонки больше не переносятся.

- Скорость симуляции по умолчанию: 2×.
- На виртуальном треке 20 км пункт питания перенесён на 14.0 км.
