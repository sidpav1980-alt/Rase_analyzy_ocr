# Trail Race Analyzer v0.0232

Виртуальный трек 20 км теперь всегда имеет простой профиль:
- 0–3 км: постоянный подъём, суммарно +500 м.
- 3–7 км: постоянный спуск на исходную высоту.
- 7–20 км: ровный участок до финиша.
- 2 виртуальных брода сохранены: 6.0 и 14.0 км.
- При загрузке реального GPX виртуальная симуляция сбрасывается.
