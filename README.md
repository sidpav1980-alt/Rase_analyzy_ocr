# Прогноз и анализ трейловых гонок — v0.63

Изменения:
- броды определяются не только по `ford=yes`, но и по геометрическому пересечению GPX с OSM `waterway=river/stream/...`;
- пересечения воды без моста показываются как «вероятные броды»;
- явные `ford=yes` показываются как подтверждённые OSM;
- близкие рукава одной реки объединяются в одно физическое пересечение;
- пауза случайного события в симуляции — ровно 3 секунды;
- профиль GPX теперь находится сверху, белый маркер показывает текущее место;
- бегун с рюкзаком и палками бежит отдельно в нижней сцене, как в макете;
- вылетающие эмодзи появляются около бегуна в нижней сцене;
- солнце/луна и время суток сохранены.
