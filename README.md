# v0.69 — интерфейс симуляции как в референсе

- Верхняя строка метрик: дистанция, набор, прогнозное время, средний темп, события, виртуальное время.
- Отдельный верхний график реального профиля GPX с белым маркером текущего положения.
- Средний блок: события текущей симуляции + карта трека и бродов.
- Нижняя большая сцена симуляции с бегуном, водой/бродами, событием, паузой и скоростью.
- Сохранены редкие события, 3-секундная пауза и 5-секундные эмодзи.
