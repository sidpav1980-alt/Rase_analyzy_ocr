# Trail Race Analyzer v0.0241

Исправления перехода между виртуальными уровнями:
- После победы на уровне жизни явно восстанавливаются до 3/3.
- После прохождения уровня следующий виртуальный трек сразу перестраивается.
- Профиль, дистанция, набор высоты, броды и ПП обновляются на данные нового уровня.
- На втором уровне больше не остаётся карта/профиль первого уровня.
- Реальный трек и его симуляция не затронуты.
