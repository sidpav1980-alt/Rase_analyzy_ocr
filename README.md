# v0.0200

- Броды в пределах 350 м объединяются в один.
- Пограничные пары вроде 7.2/7.5 и 16.1/16.4 больше не должны считаться отдельными бродами.
- В любой симуляции теперь минимум 3 случайных события.
- На длинных гонках количество событий продолжает расти.
- Максимум остаётся 2 события в час.
- Баланс положительных и отрицательных событий 50/50 сохранён.
