# v1.01

- Исправлена загрузка GPX после выбора файла.
- Причина: после удаления AbortController в v0.99 осталась ссылка на `mapAnalysisAbortController` в обработчике нового GPX; это давало ReferenceError и обрывало обработчик выбора файла.
- Убрана устаревшая ссылка.
- Добавлена более надёжная обработка `change` + `input` для iOS Safari/Chrome.
- После успешной автозагрузки явно показывается `✓ Загружен: имя.gpx` и зелёная кнопка `✓ GPX загружен`.
- Логика v1.00 (Миша 3 сек при 4×, события 50/50, анализ без прерывания) сохранена.
