# v0.71

## Автозагрузка GPX
- После выбора GPX трассы файл сразу автоматически обрабатывается — дополнительное нажатие на кнопку не требуется.
- После выбора любого из трёх эталонов (Силовая трейловая, Быстрая трейловая, Скоростная плоская) файл сразу автоматически читается и анализируется.
- Во время обработки кнопка показывает «⏳ Загрузка файла…».
- После успешной обработки кнопка становится зелёной и показывает «✓ Файл загружен».
- При ошибке кнопка меняется на «Повторить загрузку».
- Старый прогноз по-прежнему очищается при замене любого эталонного GPX и пересчитывается после успешной загрузки, когда все необходимые данные готовы.
