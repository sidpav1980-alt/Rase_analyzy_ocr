# Trail Race Analyzer v0.97 ONLINE FULL

Изменена логика темпа по участкам прогноза.

- В таблице теперь показывается **Рекомендуемый темп**, а не максимально возможный.
- Основа — **средний прогнозный темп всей гонки** после VO₂max, длительности и физиологических ограничений.
- Подъёмы замедляют темп умеренно, спуски немного ускоряют.
- Первая треть гонки чуть спокойнее среднего.
- Середина идёт около среднего прогнозного темпа.
- Последняя треть лишь немного быстрее, если рельеф позволяет.
- Все интервалы нормируются так, чтобы их сумма точно совпадала с общим прогнозом движения.

Цель — убрать раскладку вида «очень быстро первые 20–25 км, затем 9–10 мин/км».
