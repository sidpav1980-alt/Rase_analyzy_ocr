# Trail Race Analyzer v0.25 — ONLINE FULL

Динамическая калибровка строится по содержимому загруженных GPX, а не по названию файла.

Учитываются:
- дистанция;
- время;
- скорость;
- набор на км;
- длительность;
- уклоны;
- вариативность скорости.

Силовая и быстрая трейловая GPX получают динамические веса по их фактическим характеристикам.
Плоская GPX формирует скоростной якорь из реальных ровных сегментов.
Для фартлека восстановительные отрезки не должны автоматически превращать весь файл в медленный гоночный темп.

Далее применяется общая формула:
Riegel → рельеф → длительность → VO₂max → покрытие/броды при анализе трассы.
