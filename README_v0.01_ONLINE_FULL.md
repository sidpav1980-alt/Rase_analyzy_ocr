# Trail Race Analyzer v0.01 ONLINE FULL

Новая нумерация версий начинается с 0.01.

Броды:
- водотоки с известной шириной < 1 м не считаются бродами;
- пересечения в пределах 500 м от первой точки группы считаются одним бродом;
- в списке показывается только начало каждого брода.

Пример:
6.3, 6.5, 6.7 -> один брод, отображается 6.3 км.
7.1, 7.2 -> один брод, отображается 7.1 км.
16.0, 16.1 -> один брод, отображается 16.0 км.
