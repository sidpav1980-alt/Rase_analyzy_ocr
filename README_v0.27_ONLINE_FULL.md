# Trail Race Analyzer v0.26 ONLINE FULL

Исправлена модель усталости по длительности.

Теперь скорость дополнительно снижается, когда прогнозируемая гонка длится заметно дольше самого длительного загруженного эталона. Поэтому темп на 53–54 км не должен автоматически получаться быстрее темпа короткой быстрой трейловой тренировки только из-за плоского профиля.

Порядок:
1. калибровка по фактическим данным трёх GPX;
2. масштабирование плоского скоростного эталона;
3. рельеф;
4. усталость по отношению прогнозной длительности к длительности эталонов;
5. VO₂max / HR-LTHR, если доступны;
6. покрытие и броды при прогнозе с анализом GPX.


## v0.27 — неизвестное покрытие +60 сек/км и авто-пересчёт эталонов
- В прогнозе **с анализом GPX** каждый километр покрытия `unknown / неизвестно` добавляет **+1:00 мин/км**.
- Сохраняются: тропа +1:00/км, грунт +0:30/км, брод +40 секунд.
- При выборе нового файла любого из трёх эталонов текущий прогноз сразу инвалидируется.
- После успешной загрузки нового эталона приложение автоматически пересчитывает прогноз в том же режиме, который был выбран до замены файла.
- Поэтому замена «Быстрой трейловой GPX» теперь обязательно меняет расчёт, если характеристики нового файла отличаются.
