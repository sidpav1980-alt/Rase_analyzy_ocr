# Trail Race Analyzer v0.98 ONLINE FULL

Подсчёт бродов:
- водотоки с известной OSM-шириной < 1 м не считаются бродами;
- повторные пересечения одного водотока в пределах 300 м по трассе объединяются;
- если ширина в OSM неизвестна, пересечение пока остаётся возможным бродом;
- мосты продолжают учитываться отдельно.
