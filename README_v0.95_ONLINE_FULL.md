# Trail Race Analyzer v0.95 ONLINE FULL
- При наличии HR + LTHR время устойчивой интенсивности считается по ним.
- Без HR/LTHR используется обязательный VO₂max и длительность гонки.
- VO₂max теперь также ограничивает устойчивую интенсивность на многочасовой дистанции.
- «Время до закисления» — модельная оценка, не измерение лактата.
