# Trail Race Analyzer v0.87 ONLINE FULL

## v0.87 — Прогноз на гонку по эталонной activity

Добавлена отдельная вкладка **«4. Прогноз»**, а «Итог» стал вкладкой 5.

### Модель
Встроенная калибровка построена по `activity_23810601185.gpx`:
- 17.13 км;
- около +2901 м;
- elapsed 6:09;
- 85 валидных 200-метровых участков.

Формула обучается по фактическому времени прохождения участков activity:

`ln(v) = a + b1·G+ + b2·G+² + b3·G− + b4·G−² + b5·progress`

где:
- `v` — прогнозная скорость, м/с;
- `G+` — положительный уклон;
- `G−` — отрицательный уклон;
- `progress` — положение от старта к финишу (модель усталости).

Коэффициенты встроенной калибровки:
`[0.761443, -4.950940, 3.488795, 3.465680, -14.162378, -0.348810]`.

### Относительная мощность
Добавлено поле **«Относительная мощность / усилие, %»**.
Это не физические ватты:
- 100% = усилие как в эталонной activity;
- 95% = скорость модели ×0.95;
- 105% = скорость модели ×1.05.

### Прогноз
По GPX гонки приложение:
- режет трассу на короткие ~200 м отрезки;
- считает локальный уклон;
- прогнозирует скорость каждого отрезка;
- объединяет результат в таблицу по 1–10 км;
- показывает набор/сброс, уклон, темп, время отрезка и накопленное время;
- выводит прогноз финиша, средний темп и диапазон ±10%.

Можно загрузить другую timed-GPX activity и перекалибровать формулу прямо в браузере.

Для `50.gpx` при встроенной калибровке и усилии 100% модель ориентировочно даёт около **9 часов движения**; точное значение в приложении зависит от текущего сглаженного профиля GPX.

# Trail Race Analyzer v0.86 ONLINE FULL

## v0.86
- В раздел «Итог» добавлена **Пульсовая стратегия**.
- Стратегия строится автоматически из:
  - длины GPX трассы;
  - среднего пульса «Лучшей тренировки».
- Гонка делится на 4 участка:
  - начало — контролируемый пульс;
  - середина — рабочий горный диапазон;
  - поздняя часть — постепенное повышение;
  - последние ~5% — финиш без экономии при хорошем состоянии.
- На спусках приложение отдельно напоминает не удерживать высокий пульс искусственно.
- При смене фото/очистке тренировки старая пульсовая стратегия очищается.
- Все изменения v0.85 сохранены.

# Trail Race Analyzer v0.84 ONLINE FULL

## v0.84
Исправления раздела «Лучшая тренировка»:

- После выбора файла и нажатия «Загрузить и распознать» выбранный скриншот больше не сбрасывается.
- Имя выбранного файла дополнительно показывается отдельной строкой и остаётся видно после OCR.
- При выборе новой фотографии очищаются только старые результаты и поля тренировки, но новый выбранный файл сохраняется.
- При обновлении страницы поля принудительно очищаются несколько раз:
  - сразу после загрузки DOM;
  - после первого кадра;
  - через 120 мс;
  - через 500 мс;
  - при Safari `pageshow`.
  Это сделано потому, что Safari может восстанавливать значения формы уже после `DOMContentLoaded`.
- На настоящем обновлении страницы также очищается выбор файла.
- OCR timeout 60 секунд сохранён.
